# misleading accuracy in imbalanced datasets

This Python script demonstrates how a 99.4% accuracy can be misleading in machine learning. It simulates an imbalanced dataset and a classifier that always predicts the majority class, achieving high accuracy but failing to detect the minority class.

## Language

`python`

## How to Run

Run this script using Python: `python misleading_accuracy.py`
